# BalaPrep

A single-page Next.js landing site for BalaPrep. Consultation links open the supplied Calendly event in a new tab.

## Local development

Use Node.js 22 or later.

```sh
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000). Run `npm run build` to verify the production build and `npm run start` to serve it locally.

## Vercel

Import this repository as a Next.js project with the default install and build settings. Set `SITE_URL` to the production origin if you use a custom domain and want it used in canonical and Open Graph URLs. Otherwise, the site uses Vercel's production URL when available.
